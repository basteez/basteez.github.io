# Stage

A loud red, black and white Hugo theme for personal blogs. The frame is a stage: ransom-note collage titles, game-menu navigation with a ▶ cursor, posts as crooked paper notes, rubber stamps and a ticker. The reading column is the opposite: one serif face, a comfortable measure, high contrast, light or dark following the system.

![Stage theme screenshot](https://raw.githubusercontent.com/basteez/hugo-theme-stage/main/images/screenshot.png)

**Demo:** <https://basteez.github.io/hugo-theme-stage/>

Style inspired by the menus and UI of *Persona 5*. Stage is an independent fan project: it is not affiliated with or endorsed by Atlus or SEGA, and it uses no assets, logos, fonts or text from the game.

## Features

- **Collage titles rendered at build time.** Every letter is a cut-paper tile with its own font, colour, tilt and pop-in, generated by the template with a deterministic pseudo-random sequence seeded by the text. No JavaScript, no layout shift, the same output on every build. The collage is `aria-hidden`; the real text is always next to it.
- **Post titles as tape strips**: white before the first colon, red after.
- **Series** (taxonomy `series`): "Part 2 of 4" under the title, every part as a menu after the text, previous/next part.
- **Table of contents** with a ▶ cursor that follows the section you are reading, and a **reading-progress bar**.
- **Search** with [Pagefind](https://pagefind.app/), built after Hugo.
- **Comments** with Disqus or [giscus](https://giscus.app/), loaded only when the reader gets near them, never on localhost.
- **Mermaid** diagrams, loaded only on pages that have one, with a keyboard-accessible enlarged view.
- **Link-preview cards** (OpenGraph/Twitter) drawn at build time for every post and for the site, from your own settings. A **letter favicon** too.
- **Accessible**: WCAG 2.1 AA with axe-core, `prefers-reduced-motion`, a *Pause motion* button (WCAG 2.2.2), `forced-colors` and `prefers-contrast`, visible focus, decorative symbols removed from accessible names, code line numbers hidden from screen readers, links that open a new tab say so.
- **Works without JavaScript.** One small vanilla script adds the enhancements. Cross-document View Transitions where supported.
- **Self-hosted fonts** (SIL OFL): Dela Gothic One, Fraunces, Courier Prime, Anton, Literata, Fira Code.
- **i18n**: English and Italian included; every string can be overridden.

## Requirements

- Hugo **0.146.0** or later (tested on 0.146.0, 0.152.2 and 0.169.0). On Hugo older than 0.153.0 use the **extended** edition: the theme encodes WebP images.
- For search: Node.js, to run Pagefind after Hugo.

## Installation

### As a Hugo Module (recommended)

```sh
hugo mod init github.com/you/your-site   # once, if your site is not a module yet
```

```toml
# hugo.toml
[module]
  [[module.imports]]
    path = "github.com/basteez/hugo-theme-stage"
```

```sh
hugo mod get -u github.com/basteez/hugo-theme-stage
```

### As a theme folder

```sh
git submodule add https://github.com/basteez/hugo-theme-stage.git themes/hugo-theme-stage
# or download a release and unpack it into themes/hugo-theme-stage
```

```toml
# hugo.toml
theme = "hugo-theme-stage"
```

### Try the example site

```sh
git clone https://github.com/basteez/hugo-theme-stage.git
cd hugo-theme-stage/exampleSite
hugo server --renderToMemory
```

## Quick start

The smallest useful configuration:

```toml
baseURL = "https://example.org/"
title = "Jane Roe | Developer"
copyright = "Jane Roe"

[taxonomies]          # declare series; this replaces Hugo's defaults, so keep tags and categories
  category = "categories"
  tag = "tags"
  series = "series"

[markup.highlight]
  noClasses = false   # required: the theme ships its own code colours

[params]
  mainSections = ["post"]

[params.stage]
  brand = "ROE.DEV"
  [params.stage.hero]
    name = ["JANE", "ROE"]
    role = "INDEPENDENT DEVELOPER"
    stack = ["GO", "RUST", "POSTGRES"]

[[menus.main]]
  name = "Posts"
  url = "/post/"
  weight = 1
[[menus.social]]
  name = "GitHub"
  url = "https://github.com/you"
```

[`exampleSite/hugo.toml`](https://github.com/basteez/hugo-theme-stage/blob/main/exampleSite/hugo.toml) lists every setting with its default.

### Content

- **Posts** are the regular pages of `params.mainSections` (default: the section with the most pages). Page bundles (`post/my-post/index.md` with its images) are recommended.
- **About page**: any page with `layout: about`. Its content goes in a dialog box, with the blog's stats and the contact stamps.
- **Search page**: any page with `layout: search`.
- `hidden: true` keeps a page out of the RSS feed and of the post lists. Use it on the about and search pages.

## Configuration

All settings live under `params.stage`. A setting you leave out takes its default. For text settings, `""` also means "use the default".

### Identity

| Setting | Default | Description |
|---|---|---|
| `brand` | the `baseURL` host (`example.org` and `localhost` excluded), else the site title | Logo collage in the header, name in the 404 dialog, brand on the preview cards. Shown in capitals. |
| `description` | `params.description` | Site description (meta and cards) for pages without their own. |
| `since` | none | First year of the blog: footer copyright range, hero status line, ticker, about stats. |
| `dateFormat` | `":date_medium"` | Date layout for [`time.Format`](https://gohugo.io/functions/time/format/), localized. |
| `footer.text` | none | Extra footer line (HTML allowed). |
| `hero.name` | the site title | Hero name, one collage line per item (up to three). A string is split on spaces. |
| `hero.role` | none | White strip under the name. |
| `hero.stack` | `[]` | Mono line of keywords. |
| `hero.status` | `true` | The `SYS://BRAND ONLINE · BLOG SINCE …` line. |
| `hero.stats` | `true` | Posts / series / tags stamps next to the hero. |

### Home page

| Setting | Default | Description |
|---|---|---|
| `home.sections` | `["latest", "series", "contact"]` | Which sections, in which order. Each name renders `layouts/_partials/home/<name>.html`, so you can add your own. |
| `home.latest.count` | `5` | Posts shown as paper notes. |
| `home.latest.title` | i18n `homeLatest` ("NEW INTEL") | Collage heading. |
| `home.series.title` | i18n `homeSeries` | Collage heading. |
| `home.contact.title` | i18n `homeContact` | Collage heading. |
| `home.contact.rss` | `true` | Add an RSS stamp after the `social` menu entries. |
| `home.ticker.enabled` | `true` | Scrolling ticker at the bottom of the home page. |
| `home.ticker.items` | `[]` | Your own ticker lines. Empty: posts, series, tags, latest post, writing since, thanks. |

Contacts come from the `social` menu (`[[menus.social]]`: `name`, `url`, `weight`).

### Posts

| Setting | Default | Description |
|---|---|---|
| `article.toc` | `true` | Table of contents when the post has headings. `toc: false` in front matter turns it off for one post. |
| `article.readingTime` | `true` | "N min read" stamp and meta. |
| `article.progress` | `true` | Reading-progress bar. `progress: false` in front matter turns it off for one post. |
| `article.externalLinksNewTab` | `true` | External links open in a new tab, marked with ↗ and announced to screen readers. |
| `article.license` | none | Markdown line at the end of each post. `license:` in front matter overrides it. |
| `cover.field` | `"image"` | Front matter field holding the cover image. |

Front matter used by the theme: `image` (cover: page resource, `assets/` path, `static/` path or URL), `imageAlt`, `series`, `tags`, `categories`, `description`, `keywords`, `toc`, `progress`, `license`, `comments: false`, `hidden`. On about and search pages: `kicker` (about collage text), `placeholder` (search field).

### Features

| Setting | Default | Description |
|---|---|---|
| `motion.enabled` | `true` | `false` renders the whole site still, as with `prefers-reduced-motion`. |
| `search.enabled` | `true` | Pagefind markers on posts and the 404 link to search. |
| `comments.provider` | `"none"` | `"disqus"` (uses `services.disqus.shortname`) or `"giscus"`. |
| `comments.giscus.*` | | `repo`, `repoId`, `category`, `categoryId` (required); `mapping` (`pathname`), `strict` (`0`), `reactionsEnabled` (`1`), `emitMetadata` (`0`), `inputPosition` (`top`), `lang` (site language), `lightTheme` (`light`), `darkTheme` (`dark`). Values from [giscus.app](https://giscus.app/). |
| `mermaid.enabled` | `true` | Render ` ```mermaid ` blocks. |
| `mermaid.url` | Mermaid 12.3.0 ESM from jsDelivr | Pin another version, or self-host it. |
| `og.cards` | `true` | Generate preview cards for pages without a cover image. |
| `og.twitter.site` | none | Twitter/X handle, with or without `@`. |
| `og.twitter.card` | `"summary_large_image"` | |
| `favicon.letter` | first letter of `brand` | Letter of the generated favicon. |
| `favicon.ico`, `favicon.svg`, `favicon.appleTouch` | none | Your own icons (paths under `static/`). `static/favicon.svg` and `static/apple-touch-icon.png` are picked up automatically. |

Mermaid blocks take an optional caption: ` ```mermaid {caption="From source to value."} `.

### Older parameter names

Sites coming from other themes can keep these names. The `params.stage` name wins when both are set.

| Older name | Stage setting |
|---|---|
| `params.stage.name`, `.role`, `.stack` | `hero.name`, `hero.role`, `hero.stack` |
| `params.stage.latestCount` | `home.latest.count` |
| `params.description`, `params.sidebar.subtitle` | `description` |
| `params.footer.since`, `params.footer.customText` | `since`, `footer.text` |
| `params.dateFormat.published` | `dateFormat` |
| `params.article.toc`, `.readingTime` | `article.toc`, `article.readingTime` |
| `params.article.license.enabled` + `.default` | `article.license` |
| `params.comments.enabled` + `.provider`, `params.comments.giscus.*` (`repoID`, `categoryID`) | `comments.*` |
| `params.opengraph.twitter.site`, `.card` | `og.twitter.*` |
| `params.favicon` | `favicon.ico` |
| `params.featuredImageField` | `cover.field` |

`params.rssFullContent: true` puts whole posts in the RSS feed.

## Search with Pagefind

Pagefind indexes the built HTML, so it runs **after** Hugo:

```sh
hugo --gc --minify
npx pagefind@1.6.0 --site public
```

In GitHub Actions, add a step after the Hugo build:

```yaml
- name: Build the search index
  run: npx --yes pagefind@1.6.0 --site public
```

`hugo server` does not run Pagefind; the search page then says the index is not available. To try search locally, build, run Pagefind, and serve `public/` with any static server.

## Translations

The theme ships `i18n/en.yaml` and `i18n/it.yaml`. To change a string, or add a language, copy the keys you need into your site's `i18n/<lang>.yaml`. Collage texts (section heads, kickers) are shown in capitals and work best short.

## Customizing

- **Extra CSS**: create `assets/css/custom.css` in your site; it is appended to the theme's stylesheet. The colours are custom properties in `assets/css/tokens.css` (`--red`, `--paper`, `--ink`, …). The red `#e60012` is the theme's identity and every contrast ratio is computed against it, so change it only after checking contrast again.
- **Hooks**: `layouts/_partials/head/custom.html` (end of `<head>`), `layouts/_partials/footer/custom.html` (end of `<body>`), `layouts/_partials/comments/custom.html` (any other comment system, rendered in the comments box).
- **Home sections**: add `layouts/_partials/home/<name>.html` and list `<name>` in `home.sections`.
- Any template can be overridden by a file with the same path in your site's `layouts/`.

Google Analytics works through Hugo's built-in `services.googleAnalytics.id`.

## Accessibility

Checked with axe-core (WCAG 2.0/2.1 A and AA, 2.2 AA) on every page type of the example site, desktop and mobile, light and dark, with no violations. In detail:

- Animations live in the frame, never in the reading column. They stop with `prefers-reduced-motion`, and the starburst and ticker can be paused with *Pause motion* (remembered on the device) or by hovering/focusing the ticker.
- Collage text is decorative and `aria-hidden`; the same text is next to it, visually hidden.
- ▶ ▼ ↗ are drawn with CSS generated content with empty or meaningful alternative text.
- Chroma line numbers are hidden from screen readers; the code table is presentational.
- The enlarged Mermaid view is a native `<dialog>`: reachable with a button, closed with Esc, focus returns to the button.
- `forced-colors` and `prefers-contrast: more` are handled; focus is always visible.

Automated checks find only part of the problems. Test with a screen reader too.

## Development

The images the theme draws on (card background, collage tiles, favicon base) are rendered from `_source/og-cards.html`:

```sh
npm i -D playwright
node _source/render.mjs
```

The card font `assets/og/fonts/DelaGothicOne-Latin.ttf` is a Latin subset of Dela Gothic One (from 2.5 MB to 63 KB), made with fontTools:

```sh
pyftsubset DelaGothicOne-Regular.ttf --layout-features='*' \
  --unicodes="U+0020-007E,U+00A0-024F,U+0300-036F,U+1E00-1EFF,U+2000-206F,U+20A0-20CF,U+2100-214F,U+2190-21FF,U+2212,U+25A0-25FF,U+2605" \
  --output-file=DelaGothicOne-Latin.ttf
```
